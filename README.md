## 🚀 What I'm building

### 🛒 RapidMart
A multi-vendor delivery platform for food, grocery, pharmacy, shops and parcels.

- Three Flutter apps: customer, store and rider
- Laravel admin panel, plus a web store panel with a full POS
- Screen Builder: edit the app's screens and run seasonal campaigns without a release
- Snap to Shop: find products from a photo (Gemini / OpenAI)
- Live tracking, iOS Live Activities, realtime updates, branded emails
- Many markets and currencies, 7 languages with right-to-left support

**[Live demo](https://mart.rapidcodes.io)** · [Documentation](https://docs.rapidcodes.io/rapidmart/)

### 🚕 RapidTaxi
A white-label platform for ride-hailing, food and parcel delivery, with rider and driver apps and an admin panel.
**[Live demo](https://cab.rapidcodes.io)**

### 📓 Jrnl
An AI-first journaling app with a writing assistant built in.
**[jrnl.rapidcodes.io](https://jrnl.rapidcodes.io)**

### 🏠 RapidServ
A home-services marketplace with AI-powered matching and assistance.

### 💸 Xpense
An expense tracker for the Pakistani market, live on Google Play.
